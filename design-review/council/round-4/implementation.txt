## What changed
- **Quota.** There is now one account list. Each row shows a neutral number badge, a swatch of the line actually drawn, the full name, %, bar, limit and reset, the snapshot state or error, and its own refresh button. Selecting a row isolates that account in the chart. The breakdown table and legend chips are gone. The hatch is gone too; because the whole chart is projected, a label says so instead. Exact overlaps stay one grey line, and one function decides each stroke so the chart and list can't disagree. Inner date ticks are evenly spaced and short ("Nov 9"). Bars are neutral; only remaining below 30% gets red and the word "Low". The account cards and Auth Files quota cells follow the same colour rule.
- **Dashboard.** A status row now comes first. It states only what was checked, for example "No requests through current credentials in the last 3h 20m · No credential problems found · 6 credential files and 4 providers checked". It never says "healthy".
  - The second request count is labelled "Usage statistics source: 129 in this window", with the reason the two counts can differ.
  - An empty request window is one row plus a data-table disclosure.
  - Quota on the Dashboard leads with the bars, and the projection chart is behind a closed disclosure.
  - Dashboard times now use the locale's hour cycle, like the rest of the app.
- **Header.**
  - On phones, one visible "Utilities" menu holds reload, language, theme and sign out, using the same handlers as desktop.
  - From 1280px, the desktop buttons show their names.
  - The reload action is named for what it actually reloads ("Reload config and page data").
  - Plugins and Plugin Store moved their refresh into the page header.
- **Plugin notices.** The trust warning and the "plugins disabled" notice stay separate, at different severities, and the trust warning cannot be dismissed. The disabled state is a compact row with "Enable in Config Panel", and the status line no longer repeats it. Empty states link elsewhere but never install anything.
- **OAuth editors and Auth Files.**
  - Disabled buttons now look disabled.
  - "Please enter a provider first" sits under the Provider field, and both the field and Save point to it for screen readers.
  - The provider step is compact, and Back and Save are in a bar at the bottom.
  - On phones, credential cards say "Enabled" or "Disabled" next to the switch.
- **Smaller fixes.**
  - "Remember management key" in all four locales.
  - "Claude" for the provider; "Anthropic" only where it names the API.
  - Config titles no longer include YAML keys, and the header says edits apply when saved.
  - System's button reads "Configure request logging…".
  - Language names are written in their own language.
  - Every disclosure shares one style: chevron, hover, focus ring, 32px target (44px on phones).
  - Status bar colours come from theme tokens.

## Suggestions I rejected because the premise is false
- **Label 129 "since restart".** It is counted over the same window as Requests, so the label would be wrong.
- **One coloured line per account when values overlap exactly.** Identical lines print as one stroke, so colour cannot separate them. Isolating an account draws it in its own colour.
- **Merge or dismiss the plugin trust warning.** It applies every time the store is open; "disabled" is a temporary config state.
- **Per-provider "connected" status on OAuth Login.** The frontend has no data for it.
- **Fill empty space, or darken text without measuring.** Contrast measured as passing.
- **Fold the empty request flow into the KPI row, or add "last seen request".** The zero buckets need to stay inspectable, and no data supports a last-seen time.
