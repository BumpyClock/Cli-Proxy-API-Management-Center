The round 1 pass is finished. All nine acceptance items are in production code, and `bun run verify` passes locally and on Boat: 1246 tests pass, 0 fail, and the single-file build works. Nothing is committed, pushed or deployed. Nothing under `design-review/council/**` was touched.

**How I checked it.** I ran your capture script unchanged, but from a `/tmp` working directory so its output landed in `/tmp/cpamc/cap/...`. Both runs gave 34 screens, no page errors and no page-level overflow. I looked at the key screens myself. That exposed four problems the slices had missed, and I fixed them:
- **Header buttons.** My first title-alignment approach (a -3px margin) cut off the top edge of every header action button. The title line is now 34px tall on desktop instead.
- **Mobile Providers table.** It was still a 748px table scrolling sideways inside a small box. It now shows each resource as a labeled stack.
- **Logs switches.** "Hide /v0/management logs" wrapped to three lines. The switches now sit one per row on phones.
- **Quota refresh.** It said "Refresh all" on desktop too. It now says "Refresh all credentials" on desktop and "Refresh all" on phones.

**What changed, by screen.** Six parallel agents each owned separate files. I owned the shared files and pulled their work together.
- **Shell (mine).**
  - New `src/components/ui/RefreshButton.tsx`, adopted on every page. It is outlined, shows its scope in the label, and stays focusable while busy.
  - All pages share the same outer padding (Providers and the OAuth editors had their own extra padding).
  - Buttons and selects are at least 44px tall at 768px and below. Icons in buttons now have a gap before the label.
  - The off-screen skip link no longer leaves a shadow in the top-left corner; keyboard focus still shows it.
  - Empty states stack the action under the text on phones.
  - The OAuth editor breadcrumb now reads "Auth Files / OAuth Model …", and "Auth Files" links back.
  - Switches are announced as switches (`role="switch"`).
  - The request-history bar no longer shows a bare `--` when there were no requests.
- **Providers.** Columns have fixed widths, so Status and Actions no longer overlap. Prefixes and URLs truncate with a tooltip. On phones, the selected provider comes before a collapsible "Not configured" list.
- **Quick Start.** The setup steps come first, each linking to its real route. The Config step opens the client API key field. The APIKEY.FUN panel stays, below the steps, and its button says "Add APIKEY.FUN key".
- **Charts.** Markers at the same point share one label, such as "1–4", and each series is still named in the legend and data table. Edge axis labels no longer collide. A window where every bucket is zero shows a short chart with "No requests in this window". Daily usage the backend doesn't report shows a compact "Not reported" block, never zeros.
- **Logs.** The "Z INFO" text was a real parser bug, not a fixture artifact. The timestamp pattern didn't accept a trailing `Z` or offset, and `status=200` was never recognised. Both are fixed. Structured columns that no loaded line uses are hidden. On phones each line wraps under its time and level.
- **Auth Files.**
  - Mobile cards are compact. Request history and timestamps sit behind a "Details" button.
  - Section and provider tabs fade at the edge when more items are off screen.
  - The search placeholder is shorter and no longer runs under the icon.
  - Row actions open a menu from a labeled button.
- **OAuth.**
  - Each description sits under its provider name, and the actions are in the same place on every row.
  - Login buttons all say "Log in with …".
  - In both editors, Save is disabled until a provider is chosen, with the reason shown next to it, and "Save/Update" is now "Save".
- **Config, Plugins and System.**
  - The API key help now explains what client keys are for.
  - BestProxy is a quiet optional link under Proxy URL.
  - The plugins-disabled warning links to the existing `/config?field=pluginsEnabled`.
  - Each plugin page has one refresh button.
  - System model counts pluralise correctly and appear once, and the Copy button says "Copy version info".
- **Text.** Every new or changed label is in all four locales. User-facing notes are in `docs/workspace-redesign.md` under "Design council round 1 fixes".
